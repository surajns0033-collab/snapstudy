# 📸 SnapStudy

**Snap a page of notes. Get a study kit — in seconds.**

SnapStudy turns a **single photo** of study material — handwritten notes, a lecture slide, a textbook page, a diagram, or a whiteboard — into a **structured study kit**: a clean summary, the key points, flashcards, and a self-test quiz. All of it is read and generated by **Gemma 4**, natively multimodal, through the **Gemini API**.

## Demo (60 seconds)

https://snapstudy-sigma.vercel.app/
1. **Snap** — take a photo of your notes (or upload an image).
2. **Generate** — one tap. Gemma 4 reads the actual image and returns a study kit.
3. **Study** — read the summary, flip through flashcards, and take the quiz.

No OCR pipeline. No copy-pasting. The image goes straight to the model.

---

## Why this is a real Gemma 4 build

- **Gemma 4 is the product.** Every summary, key point, flashcard, and quiz question is a Gemma 4 inference. Remove Gemma 4 and there is no app.
- **Genuinely multimodal.** The photo is sent as **native inline image data** to the model — Gemma 4 reasons over the pixels, not a text approximation.
- **Grounded output.** The prompt instructs the model to use only what is visible in the image and never invent facts.
- **Structured output.** The model returns a single JSON object that the app parses, coerces, and renders as flashcards and a quiz.

The model identifier is configurable via `GEMMA_MODEL` and the shipped default is **`gemma-4-26b-a4b-it`**.

## Architecture

```
Browser (camera / upload)
      │  POST /api/study  (base64 image)
      ▼
Next.js route handler (Node runtime)   ← API key stays here, server-side only
      │
      ▼
GemmaStudyClient  →  @google/genai SDK
      │
      ▼
Gemini API  →  Gemma 4
      │  structured JSON study kit
      ▼
Validate & parse  →  Flashcards / Quiz / Summary in the UI
```

- [`src/lib/gemma.ts`](src/lib/gemma.ts) — the only place that calls the provider (multimodal inline data, JSON output, timeout, typed errors).
- [`src/lib/study.ts`](src/lib/study.ts) — the Gemma 4 prompt + resilient JSON parser.
- [`src/app/api/study/route.ts`](src/app/api/study/route.ts) — server-only endpoint on the Node runtime.
- [`src/components/SnapStudy.tsx`](src/components/SnapStudy.tsx) — camera capture + flashcard/quiz UI.

## Quick start

```bash
npm install
cp .env.example .env.local     # add your GEMINI_API_KEY
npm run dev                    # http://localhost:3000
```

Get a key from Google AI Studio: <https://aistudio.google.com/app/apikey>.

### Configuration

| Variable | Required | Default | Description |
| --- | --- | --- | --- |
| `GEMINI_API_KEY` | ✅ | — | Server-only key for the Gemini API. Never exposed to the browser. |
| `GEMMA_MODEL` | ❌ | `gemma-4-26b-a4b-it` | The Gemma model identifier. Never hardcoded in feature logic. |

### Production

```bash
npm run build
npm start
```

Deploy to Vercel or any Node host. Set `GEMINI_API_KEY` in the platform's secret store.

## Security

- The API key is read **only on the server** and is never `NEXT_PUBLIC_`.
- Model output is rendered as **text** — never via `dangerouslySetInnerHTML`.
- Uploads are validated (type + size) before any AI call and are **not stored**.
- Errors are typed and safe — no stack traces reach the user.

## Limitations

- Output can be wrong or incomplete; treat it as a study aid.
- Model availability depends on your API key and region — override `GEMMA_MODEL` if needed.
- Very low-quality or blurry photos reduce accuracy.
